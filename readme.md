To run this project, you need to have Node.js and npm installed on your machine. Follow the steps below to set up and run the project:
1. login to mongo db on chrome
2. on mongodb compass conect with it using ip address on mongodb
3. to run backend server a) cd backendcopy
                         b) nodemon src/index.js
4. to run frontend server a) cd copyfront
                         b) npx parcel index.html
